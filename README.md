# Forty years of loud music

A single-page listening history: 52 rock and metal songs from 1984 to 2025,
grouped by style and era, with a link to each one.

Static HTML, no build step, no dependencies, no analytics. Fonts are
self-hosted (Libre Franklin, Newsreader, Martian Mono, all open licence).
Open `index.html` directly or serve the folder.
