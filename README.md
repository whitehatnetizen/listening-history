# Dad's Metal Playlist

A single-page listening history: 52 rock and metal songs, newest first,
from 2025 back to 1984, grouped by style and era, with a link to each one.

Static HTML, no dependencies, no analytics, nothing loaded from other
sites. Song thumbnails are saved in `thumbs/`; the font (Figtree, open
licence) is self-hosted in `fonts/`.
Open `index.html` directly or serve the folder.
